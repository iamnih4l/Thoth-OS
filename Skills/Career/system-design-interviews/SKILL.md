# System Design Interviews

## Purpose
Master the system design interview format used by Google, Meta, Amazon, and other top tech companies.

## When to Activate
- System design interview preparation
- Architecture interview practice
- Senior engineering interviews

## When NOT to Activate
- Coding interviews (use DSA skill)
- Behavioral interviews

## Workflow
1. **Understand** - Analyze requirements
2. **Research** - Gather relevant information
3. **Plan** - Design the approach
4. **Execute** - Produce the deliverable
5. **Review** - Quality check and iterate
6. **Deliver** - Finalize and document

- [ ] Objectives clearly defined
- [ ] Target audience identified
- [ ] Best practices applied
