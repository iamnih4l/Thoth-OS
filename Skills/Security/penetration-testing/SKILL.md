# Penetration Testing

## Purpose
Proactively discover security vulnerabilities through systematic testing methodologies.

## When to Activate
- Pre-launch security assessment
- Regular security testing cycles
- After significant code changes

## When NOT to Activate
- Production systems without authorization
- Systems owned by others

## Workflow
1. **Understand** - Analyze requirements and constraints
2. **Plan** - Design the approach
3. **Implement** - Build with best practices
4. **Validate** - Test and verify
5. **Document** - Capture decisions and usage
6. **Review** - Quality assurance

## Checklist
- [ ] Requirements understood
- [ ] Approach designed
- [ ] Best practices applied
- [ ] Edge cases handled
- [ ] Tests or validation complete
- [ ] Documentation updated
