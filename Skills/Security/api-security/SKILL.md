# API Security

## Purpose
Protect API endpoints from unauthorized access, abuse, and common attack vectors.

## When to Activate
- API development and review
- Rate limiting implementation
- API key management

## When NOT to Activate
- Internal-only APIs with trusted callers (still recommended)

## Workflow
1. **Understand** - Analyze requirements and constraints
2. **Plan** - Design the approach
3. **Implement** - Build with best practices
4. **Validate** - Test and verify
5. **Document** - Capture decisions and usage
6. **Review** - Quality assurance
