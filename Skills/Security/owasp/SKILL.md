# OWASP Top 10

## Purpose
Protect web applications against the most critical security risks as defined by OWASP.

## When to Activate
- Security audit of web applications
- Building new web features
- Security review checklist

## When NOT to Activate
- Non-web applications
- Hardware or physical security

## Workflow
1. **Understand** - Analyze requirements and constraints
2. **Plan** - Design the approach
3. **Implement** - Build with best practices
4. **Validate** - Test and verify
5. **Document** - Capture decisions and usage
6. **Review** - Quality assurance

## Checklist
- [ ] Requirements understood
- [ ] Approach designed
- [ ] Best practices applied
- [ ] Edge cases handled
