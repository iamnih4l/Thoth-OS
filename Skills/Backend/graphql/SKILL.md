# GraphQL

## Purpose
Build flexible GraphQL APIs that enable efficient data fetching with proper schema design and resolver implementation.

## When to Activate
- GraphQL API development
- Schema design
- Migrating from REST to GraphQL

## When NOT to Activate
- Simple CRUD APIs (REST is simpler)
- APIs with no frontend consumer flexibility needs

## Workflow
1. **Understand** - Analyze requirements and constraints
2. **Plan** - Design the approach
3. **Implement** - Build with best practices
4. **Validate** - Test against requirements
5. **Document** - Capture decisions
6. **Review** - Quality check
