# REST API Design

## Purpose
Create well-designed REST APIs that follow conventions, are easy to consume, and scale gracefully.

## When to Activate
- Designing new API endpoints
- API standardization
- API documentation

## When NOT to Activate
- GraphQL APIs (use GraphQL skill)
- Internal function calls

## Workflow
1. **Understand** - Analyze requirements and constraints
2. **Plan** - Design the approach
3. **Implement** - Build with best practices
4. **Validate** - Test against requirements
5. **Document** - Capture decisions
6. **Review** - Quality check

## Checklist
- [ ] Requirements understood
- [ ] Approach designed
- [ ] Best practices applied
- [ ] Edge cases handled
- [ ] Tests written
- [ ] Documentation updated
