# MongoDB

## Purpose
Build document-oriented databases with MongoDB using proper document modeling and query patterns.

## When to Activate
- Document-oriented data requirements
- Flexible schema needs
- MongoDB Atlas deployment

## When NOT to Activate
- Highly relational data (use PostgreSQL)
- Transactions-heavy workloads
