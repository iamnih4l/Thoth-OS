# Authentication

## Purpose
Build production-grade authentication and authorization systems that are secure, scalable, and user-friendly.

## When to Activate
- Building login/signup systems
- OAuth2 integration
- Role-based access control
- Session management

## When NOT to Activate
- Internal tools with no auth needs
- Already using managed auth (Auth0, Clerk)

## Workflow
1. **Understand** - Analyze requirements and constraints
2. **Plan** - Design the approach
3. **Implement** - Build with best practices
4. **Validate** - Test against requirements
5. **Document** - Capture decisions
6. **Review** - Quality check
