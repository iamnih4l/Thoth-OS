# Kubernetes

## Purpose
Orchestrate containerized workloads at scale with Kubernetes for high availability and efficient resource utilization.

## When to Activate
- Production container orchestration
- Auto-scaling requirements
- Multi-service deployment

## When NOT to Activate
- Single-container applications (Docker Compose suffices)
- Serverless architectures

## Workflow
1. **Understand** - Analyze requirements and constraints
2. **Plan** - Design the approach
3. **Implement** - Build with best practices
4. **Validate** - Test and verify
5. **Document** - Capture decisions and usage
6. **Review** - Quality assurance
