# Terraform

## Purpose
Provision and manage cloud infrastructure declaratively with version control, reproducibility, and team collaboration.

## When to Activate
- Cloud infrastructure provisioning
- Multi-environment management
- Infrastructure automation

## When NOT to Activate
- Manual one-time setups
- Managed platforms (Vercel, Railway) that handle infrastructure

## Workflow
1. **Understand** - Analyze requirements and constraints
2. **Plan** - Design the approach
3. **Implement** - Build with best practices
4. **Validate** - Test and verify
5. **Document** - Capture decisions and usage
6. **Review** - Quality assurance
