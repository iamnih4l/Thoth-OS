# Accessibility

## Purpose
Ensure web applications are usable by everyone, including people with disabilities, meeting WCAG standards.

## When to Activate
- Any user-facing web interface
- Accessibility audits
- Component library development

## When NOT to Activate
- Internal tools with no accessibility requirements (rare)

## Workflow
1. **Understand** - Analyze requirements and constraints
2. **Plan** - Design the approach
3. **Implement** - Build with best practices
4. **Validate** - Test against requirements
5. **Document** - Capture decisions
6. **Review** - Quality check

## Checklist
- [ ] Requirements understood
- [ ] Approach designed
- [ ] Best practices applied
- [ ] Edge cases handled
- [ ] Tests written
