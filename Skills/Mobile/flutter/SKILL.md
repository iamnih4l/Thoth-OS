# Flutter Development

## Purpose
Develop native-quality mobile apps for iOS and Android from a single Flutter codebase.

## When to Activate
- Cross-platform mobile app development
- Flutter widget and state management
- Platform-specific integrations

## When NOT to Activate
- Web-only applications
- Native iOS/Android (non-Flutter) projects

## Workflow
1. **Understand** - Analyze requirements and constraints
2. **Plan** - Design the approach
3. **Implement** - Build with best practices
4. **Validate** - Test and verify
5. **Document** - Capture decisions and usage
6. **Review** - Quality assurance

## Checklist
- [ ] Requirements understood
- [ ] Approach designed
