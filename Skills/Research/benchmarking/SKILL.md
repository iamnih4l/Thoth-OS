# Benchmarking

## Purpose
Create rigorous benchmarks that produce reliable, actionable comparison data for decision-making.

## When to Activate
- Technology evaluation
- Model comparison
- Performance testing
- Vendor selection

## When NOT to Activate
- Subjective comparisons
- Decisions where benchmarks aren't the key factor

## Workflow

2. **Research** - Gather relevant information
3. **Plan** - Design the approach
4. **Execute** - Produce the deliverable
5. **Review** - Quality check and iterate
6. **Deliver** - Finalize and document
