# Mermaid Diagrams

## Purpose
Produce clear, maintainable diagrams as code for architecture, flows, and data relationships.

## When to Activate
- Architecture visualization
- Process flow documentation
- Database schema diagrams
- Sequence diagrams for API flows

## When NOT to Activate
- Design mockups (use design tools)
- Presentation graphics (use presentation tools)

## Workflow
1. **Identify need** - What specific utility task is required?
2. **Apply** - Use the appropriate technique or tool
3. **Validate** - Verify correctness
4. **Document** - Note usage for future reference

## Checklist
- [ ] Task clearly defined
- [ ] Correct tool/technique applied
- [ ] Output validated
- [ ] Edge cases considered

## Input Format
```yaml
task: 'Utility task description'
input: 'Data or context to process'
```

## Output Format
```markdown
## Result
[Processed output with explanation]
```
