# Markdown

## Purpose
Create clear, well-formatted documentation using Markdown syntax and best practices.

## When to Activate
- Documentation writing
- README creation
- Technical writing
- Note-taking

## When NOT to Activate
- Rich document formatting needs (use proper word processors)
- Presentation content

## Workflow
1. **Identify need** - What specific utility task is required?
2. **Apply** - Use the appropriate technique or tool
3. **Validate** - Verify correctness
4. **Document** - Note usage for future reference

## Checklist
- [ ] Task clearly defined
- [ ] Correct tool/technique applied
- [ ] Output validated
- [ ] Edge cases considered

## Input Format
```yaml
task: 'Utility task description'
input: 'Data or context to process'
```

## Output Format
```markdown
## Result
[Processed output with explanation]
```

## Examples
See workflow for standard usage.

## Edge Cases
- Handle edge cases specific to the utility
- Consider encoding, format, and compatibility issues

## References
- Official documentation for the utility tool
