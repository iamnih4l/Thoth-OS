# Frontend Skill (design-engineering)

Thoth OS includes a dedicated, automatically applicable Frontend Skill called `design-engineering`. This skill ensures that frontend applications, landing pages, and components generated by the OS do not feel like generic "AI defaults."

## What is it?
The `design-engineering` skill acts as an uncompromising design director and frontend expert. It encodes rules for typography, layout rhythms, accessible color contrast, purposeful motion, and component polish.

## When does it activate?
The Task Orchestrator will automatically route the task to utilize this skill whenever the user is:
- Creating a new website, landing page, or dashboard.
- Building a React interface, Next.js application, or interactive UI.
- Redesigning an existing frontend.
- Prototyping a UI.

**Note:** It does *not* activate for backend tasks, generic coding questions, or infrastructure configurations.

## How it Influences the Frontend Process
When activated, the skill guides the agent to follow a strict sequential workflow:

1. **Brief Inference:** Determine what is being built, the target audience, and the aesthetic vibe. Set "The Three Dials" (`DESIGN_VARIANCE`, `MOTION_INTENSITY`, `VISUAL_DENSITY`).
2. **System Selection:** Select an official design system (e.g., Radix, shadcn) if it fits the brief.
3. **Visual System Construction:** Enforce spacing rhythms, responsive limits, and typography (banning defaults like the "AI beige/brass" palette or overused fonts like `Inter` for creative briefs).
4. **Motion Design:** Introduce interaction using custom easing (never `ease-in`), spring physics, and CSS `transition` properties. Ensure elements scale correctly and do not animate from `scale(0)`.
5. **Quality Review:** Perform self-QA across three lenses: *Critique*, *Audit*, and *Polish*.
