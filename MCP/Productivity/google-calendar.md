# Google Calendar MCP Integration

## Why It Exists
Manage events and check availability in Google Calendar.

## Setup Steps
1. Navigate to the MCP settings in your Antigravity workspace.
2. Add a new server configuration for Google Calendar.
3. Obtain necessary API keys or credentials.
4. Add the credentials to your environment variables or secure vault.

## Authentication
- **Type**: API Key / OAuth / Token
- **Required Scopes/Permissions**: Read, Write (adjust as needed)

## Example Workflows
- **Workflow 1**: Automating routine tasks using Google Calendar tools.
- **Workflow 2**: Querying Google Calendar for context during agent interactions.

## Tools Available
- list_events, create_event
