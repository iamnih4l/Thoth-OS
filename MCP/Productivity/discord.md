# Discord MCP Integration

## Why It Exists
Send messages and interact with Discord servers.

## Setup Steps
1. Navigate to the MCP settings in your Antigravity workspace.
2. Add a new server configuration for Discord.
3. Obtain necessary API keys or credentials.
4. Add the credentials to your environment variables or secure vault.

## Authentication
- **Type**: API Key / OAuth / Token
- **Required Scopes/Permissions**: Read, Write (adjust as needed)

## Example Workflows
- **Workflow 1**: Automating routine tasks using Discord tools.
- **Workflow 2**: Querying Discord for context during agent interactions.

## Tools Available
- send_message, list_channels
