# OpenRouter MCP Integration

## Why It Exists
Access various open-source and proprietary models via OpenRouter.

## Setup Steps
1. Navigate to the MCP settings in your Antigravity workspace.
2. Add a new server configuration for OpenRouter.
3. Obtain necessary API keys or credentials.
4. Add the credentials to your environment variables or secure vault.

## Authentication
- **Type**: API Key / OAuth / Token
- **Required Scopes/Permissions**: Read, Write (adjust as needed)

## Example Workflows
- **Workflow 1**: Automating routine tasks using OpenRouter tools.
- **Workflow 2**: Querying OpenRouter for context during agent interactions.
