# Firebase MCP Integration

## Why It Exists
Interact with Firestore and Firebase Realtime Database.

## Setup Steps
1. Navigate to the MCP settings in your Antigravity workspace.
2. Add a new server configuration for Firebase.
3. Obtain necessary API keys or credentials.
4. Add the credentials to your environment variables or secure vault.

## Authentication
- **Type**: API Key / OAuth / Token
- **Required Scopes/Permissions**: Read, Write (adjust as needed)

## Example Workflows
- **Workflow 1**: Automating routine tasks using Firebase tools.
- **Workflow 2**: Querying Firebase for context during agent interactions.

## Tools Available
- read_document, write_document
