# PostgreSQL MCP Integration

## Why It Exists
Direct integration with PostgreSQL databases for querying and schema management.

## Setup Steps
1. Navigate to the MCP settings in your Antigravity workspace.
2. Add a new server configuration for PostgreSQL.
3. Obtain necessary API keys or credentials.
4. Add the credentials to your environment variables or secure vault.

## Authentication
- **Type**: API Key / OAuth / Token
- **Required Scopes/Permissions**: Read, Write (adjust as needed)

## Example Workflows
- **Workflow 1**: Automating routine tasks using PostgreSQL tools.
- **Workflow 2**: Querying PostgreSQL for context during agent interactions.

## Tools Available
- execute_query, get_schema
